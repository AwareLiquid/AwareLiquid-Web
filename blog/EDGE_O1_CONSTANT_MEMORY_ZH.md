# 0.381 MB 恒定状态:注意力自由的 O1 模型,CPU 上跑 1M token 上下文

> 知乎 / 掘金 / CSDN 技术长文(A1)· 2026-08-28
> 所有数字均有可复现来源(M1 仓库 BENCHMARKS.md / RESULTS.md),不是宣传话术。

---

## TL;DR

- 一个 **48M 参数、注意力自由(attention-free)** 的语言模型,推理时携带状态**恒定 0.381 MB**——无论上下文是 512 token 还是 1,048,576 token。
- 对比:同等规模 Transformer 的 KV cache 在 1M 上下文时约 **3 GB**,差距 **8,063 倍**。
- 全程 **CPU 可跑**,不需要 GPU。
- 诚实声明:它**不追求**语言质量领先(详见文末"它不是万灵药"一节)——它的价值主张是**内存形态因子与效率**。

---

## 问题:Transformer 的内存天花板

Transformer 的 KV cache 随上下文长度 **线性增长(O(T))**。这不是理论担忧,是实测:

| 上下文长度 | KV cache(125M 规模) | O1 携带状态 |
|---:|---:|---:|
| 512 | ~1.5 MB | 0.381 MB |
| 128k | ~384 MB | 0.381 MB |
| 1,048,576(1M) | **~3 GB** | **0.381 MB** |

在 1M token 上下文时,KV cache 需要 3 GB 显存/内存——绝大多数边缘设备(手机、树莓派、嵌入式板卡)直接出局。**上下文长度成了内存预算,而不是模型能力**。

## 思路:把 KV cache 换成恒定状态

O1 的做法很直接:把注意力块全部替换成**递归混合器(recurrent mixer)**,携带一个**固定尺寸的状态张量**,随每一步输入更新。

```
input → 液态核心(13 protofilament × 5 时间尺度)→ 恒定状态 h (0.381 MB)
                                          ↑ 状态与上下文长度无关
```

关键性质(已测,非推断):

1. **状态恒定**:从 512 token 扫到 1M token(2048× 上下文跨度),携带状态**一位不变**——flat to the decimal。
2. **流式是 O(1)**:麦克风/传感器/对话流永不关闭,内存与延迟不随时长漂移。
3. **快权重跨窗口记忆**:离散 key→value 绑定存在状态里,丢掉的上下文还能跨窗口召回(实测 0.56,attention/LoRA 结构上为 0)。

## 实测数据(多 seed,可复现)

| 结果 | 数字 | 备注 |
|---|---|---|
| O(1) 推理状态 @1M tokens | **0.381 MB 恒定**,比 KV 小 8,063× | 注意力自由(ARR)变体专属 |
| 跨窗口关联召回(快权重) | **0.56**(3 seeds)vs attention/LoRA **0.000** | 离散 K→V 绑定,不是长上下文 LM |
| 跨会话快照/恢复 | bit-exact,控制组在随机水平 | 召回任务方差较高 |
| 不规则采样鲁棒性(NASA 电池) | 丢 80% 样本仅劣化 **+7.7%**(LSTM +31.1%,GRU +32.8%) | 流式场景直接受益 |

## 为什么这对边缘设备重要

边缘设备的共性:**硬件不能增长,但流不能停**。

- **可穿戴**:麦克风/传感器永远开着,状态必须恒定——5,120 字节的唤醒词模型(O1-Sound)就是这条线的产物。
- **车载/工业**:数小时的传感器流,内存不能随会话膨胀。
- **电池管理**:NASA 电池数据实测,80% 采样丢失下 O1 只劣化 +7.7%,LSTM/GRU 劣化 31%+——因为液态核心的连续时间结构天然适配不规则采样。

## 它不是万灵药(诚实声明)

为了让读者(和潜在的复现者)不被误导,以下是我们自己的坏消息:

1. **语言质量不是卖点**。125M 规模 WikiText-103 收敛 PPL:现代 Transformer 78.86 < MT-LNN 88.93。**我们不声称质量领先**——这是架构的诚实边界。
2. **O(1) 只属于注意力自由变体(O 系列)**。混合 M 系列仍有注意力,推理内存是 O(T) 的,训练内存比 Transformer 更差。
3. **没有长上下文 LM 增益**。跨窗口状态是情节性 key→value 记忆,不是压缩的分布式上下文——窗口外 LM 是实测的 null。
4. **我们撤回过一个夸大声明**。早期"−28~34% PPL"的适配器数字已被撤回(PEFT 静默冻结了 MT 适配器,只有 LoRA 在训练)。完整记录在 RESULTS.md——**科学诚实是信誉的底线**。
