# 融资冷启动 Playbook — 学 Polsia，用我们自己的产品跑我们自己的轮次

> 目标:把 AwareLiquid/HyperCode 的"第一笔资金"做成一次**可复制的冷启动**——像 Polsia 那样用自家 agent 跑外联,但**不制造垃圾邮件**。
> 关键结论先给:Polsia 真正的杠杆不是"发得多",而是**"公开证明 + 分发匹配"**。外联只是把注意力收口。

---

## 一、Polsia 到底做了什么(事实)

| 动作 | 细节 |
|---|---|
| **用自己的产品跑自己的轮次** | agent 做:投资人筛选 → 个性化外联 → 解析回复 → 约会议 → 准备 data room → 答尽调;创始人**只在终局电话出现**。原话:"The round itself is the clearest example of what I built." |
| **公开融资大盘** | `polsia.com/live`:实时指标 + 外联过程可见。融资本身就是营销——"越多人讨论 → 流量越大 → 指标越好 → 越多投资人看" |
| **分发匹配的投资人名单** | 选 **Sound Ventures(Ashton Kutcher)、Vaynerfund(Gary Vee)** 这类"放大器型"基金——因为 Polsia 的获客靠 X/LinkedIn 的 build-in-public,而这些人正好会转发 |
| **叙事钩子** | "我的 AI 在替我融这轮"(150 个投资人邮件)、"一人公司、零员工" |
| **反垃圾** | 个性化(按 profile 单独起草)、退订兜底、只发高相关对象、用正规 agent 基建(Agentmail / Anchor Browser 等) |
| **结果** | $1M pre-seed(基本没花)→ 60 天后 $30M Series A @ $250M,~$10M ARR。True Ventures 领投 pre-seed 并**跟投 A 轮**(最强尽调信号) |

**诚实的另一面**:有投资人质疑"A 轮靠的是他的网络和已投股东,不是冷邮件"。这恰恰说明——**真正起作用的是公开分发 + 已有 lead 的背书**,不是邮件量。

## 三、实施路线(30–60 天)

**Phase 0 — 备好"证明"与物料(3–5 天)**
- 一页 Teaser + 更新 deck(已有 `HyperCode-Product-Deck.pptx`)+ data room(deck/指标/模型结果/cap table/use of funds)。
- 建一个公开页 `awareliquid.ai/raise`(或子域):指标(发布数、模型下载、star、试用注册、MRR)+ 外联活动流(**脱敏**:只显示"已联系 N 家 / 类型 / 状态",不显示具体收件人)。
- 统一叙事:**"AI agent 跑一个真实业务的冷启动,包括它自己的融资"**。

**Phase 1 — 用我们自己的 agent 搭外联引擎(5–10 天)**
- **名单**:手工策展 80–150 个**真正 fit** 的基金/天使(阶段、支票、thesis、地域、近 6 个月出手、组合重叠)。来源:OpenVC / Crunchbase / Signal / 你自己的网络。**不买名单、不爬未授权邮箱**。
  - 每行字段:机构、GP、thesis 关键词、最近一笔、warm-intro 路径、对方公开渠道。
- **个性化**:每条外联由 agent 生成**唯一钩子**(对方最近的出手/观点 ↔ 我们的某个具体实测结果,如"你们押注 edge AI / agent memory——我们这边 0.381MB 恒定状态 + 跨会话记忆,附一个可复现结果")。用 **Awareness** 存每个投资人 profile + 历史互动 → 跟进有上下文、不重复。
- **节奏**:soft intro(价值优先,先给一个模型发布/研究结果)→ 跟进 → 再 ask。**首封冷邮件不带附件、不用短链、纯文本、人类语气**,reply-to 一个真人监控的邮箱。
- **回复处理**:agent 解析回复、起草回信、约会议;创始人只上高信息量的电话。用 HyperCode 的 checkpoint/memory 保持线程上下文。

**Phase 2 — 公开分发闭环(贯穿)**
- 投资人名单优先 **会公开转发的放大器**(播客/博主型 GP、operator angel)。
- 里程碑即钩子:每次模型发布 / benchmark / 大版本 → 一条 build-in-public 帖 → 顺手 re-engage 名单。
- 创始人内容:把"AI 在跑我们的融资"做成**诚实版**叙事(agent 做 sourcing/起草/分诊,人做电话),公开在 live 页。

**Phase 3 — 尽调与合规(贯穿)**
- **证据台账**:所有数字可复现(我们已有 RESULTS/复现文化)——尽调时这是最强的。
- **实体决策:新加坡主体**。用户已定:**AwareLiquid Pte. Ltd.(新加坡)**。
  - 为什么好:新加坡是**offshore/中立**结构,常见于"面向全球(含美国)投资人"的架构;企业所得税友好;基金/家办生态成熟(DOS/Pte Ltd + 可搭开曼/BVI 控股以容纳美/中/东南亚 LP)。
  - **但要注意**:公司注册地 ≠ 证券法适用地。**只要向"美国人士"推介/发股,美国联邦证券法(Reg D/506(b)/(c))依然适用**,与公司设在哪无关。向新加坡投资人则适用新加坡 SFA(私募豁免对 accredited/institutional 投资人)。→ **主体在新加坡能规避"公开募资宣传"的部分限制,但对美 LP 仍需 506(b) 既有关系 / 506(c) 验证 accredited。**
  - 建议结构:运营主体新加坡 Pte Ltd + 融资层面按投资人构成决定是否加开曼控股;正式对外前**咨询新加坡 + 美国各一名律师**。
- **公开页合规**:`/raise` 页**只放产品/技术指标**,明确写 "not an offer to sell securities";不放募资邀约、不放价/条款。数据:**GDPR/CAN-SPAM/PIPL**——只用可合法触达的商业邮箱、一键退订、保留同意记录。

## 四、反垃圾硬性 Guardrail(必须全满足)

1. **只发 fit 达阈值的目标**(thesis 匹配打分),不做无差别群发。
2. **域名预热**:专用子域,SPF/DKIM/DMARC 全配;每日发送上限(起步 20–30/天/域),渐进加量。
3. **一键退订** + 全局**抑制名单**(退订/硬退/投诉过的人永不再发)。
4. **首封不带附件、不放短链**;纯文本、真人签名、reply-to 真人。
5. **人工在环**:任何新客群的首次发送前,创始人抽检个性化质量;发现模板化立即停。
6. **监控送达率**:退信率/投诉率超阈值**自动暂停**,排查后再开。
7. **永不**买名单、爬未授权邮箱、伪造身份、绕过退订。

> 判断标准:如果这封邮件被公开截图,我们**不觉得丢人**——才发。

## 五、要盯的指标

- 正向回复率(目标:个性化 80–150 家里 ≥15–25% 有回复,其中正向 ≥8%)
- 约到的会议数 / 进入 data room 的比例
- 送达率(退信 <2%、投诉 <0.1%)
- pipeline 金额 / 距离 term sheet 的对话数

---

## 六、一句话总结

**别做"大量冷邮件"——做两件事:① 用 HyperCode/Awareness 把外联做得像人一样精准且可公开;② 把公开的产品指标当成真正的融资证据(Polsia 的 live 大盘比任何 deck 都硬)。** 外联是收口,分发才是引擎。
