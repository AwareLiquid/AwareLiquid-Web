How we run our own fundraise

Honest version: the agent does the volume work; the founder does the human work. This is the same product we sell, applied to ourselves.

What the agent does

1
Sourcing
Builds a curated list of funds/angels that fit our thesis, stage and geography — no purchased lists.
2
Personalised drafting
One unique hook per investor (their recent bet ↔ one of our reproducible results). No templates.
3
Reply triage
Parses replies, drafts responses, schedules calls, keeps context in memory so follow-ups never repeat.

What the founder does

✓
The calls
Every high-context conversation and the term sheet are human. The agent never signs anything.
✓
The relationship
Founder-to-investor trust is not delegated.
✓
The judgement
Which investors, which terms, when to walk — human decisions.

Anti-spam is a design rule, not an afterthought: fit-scored targets only, a warmed sending domain, one-click unsubscribe and a global suppression list, no attachments or link shorteners on a first touch, and a human spot-check before any new segment is contacted.

Why build in public

A public metric page is a stronger piece of evidence than a slide. Research results ship as open weights and reproducible scripts; the fundraise runs on the same agent we sell. If it works here, it works for a customer.
