الوصول إلى API

متوافق مع OpenAImodel: awareliquid-m1streaming

M1 نموذج هجين بحجم 1.1B مع مُهايئ تكرار سائل MT-v2s (ذاكرة عرضية سريعة الأوزان + تلاشٍ انتقائي — البنية الموثّقة في القياسات لدينا). يمكنك استدعاؤه بأي SDK من OpenAI أو عبر HTTP مباشرة.

1  احصل على رمز وصول

سجّل الدخول في relay.awareliquid.ai وأنشئ رمز API (لوحة التحكم ← Tokens). تُعرض الحصص والاستخدام لكل رمز على حدة.

2  استدعِ النموذج

curl https://relay.awareliquid.ai/v1/chat/completions \
  -H "Authorization: Bearer $YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "awareliquid-m1",
    "messages": [{"role": "user", "content": "عرّف عن نفسك في جملة"}],
    "max_tokens": 128,
    "stream": true
  }'

أو باستخدام SDK بايثون الخاص بـ OpenAI:

from openai import OpenAI
client = OpenAI(base_url="https://relay.awareliquid.ai/v1",
                api_key="YOUR_TOKEN")
r = client.chat.completions.create(
    model="awareliquid-m1",
    messages=[{"role": "user", "content": "Hello!"}],
)
print(r.choices[0].message.content)
